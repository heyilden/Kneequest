Les tests concernent les fichiers livres dans ce dossier, pas une installation deja activee dans ton compte Google.

Ce qui a ete execute

Tests purs dans Node.js pour le moteur de selection, les dates, les calculs, la serialisation et les conflits. Tests d'interface sur Chromium gere par l'environnement, en injectant les scripts et styles exacts de la livraison avec page.set_content. Les parcours couvrent bibliotheque, profils, chronos, STOP, bilan, suppression, bonus, ecrans mobiles et formulaire d'installation.

Le test de couverture utilise six groupes synthetiques entierement autorises dans les trois types d'effort : 18 couples couverts en trois semaines, puis controle de non-repetition sur douze semaines. Ce resultat ne promet pas la meme duree pour ton programme reel, dont certaines variantes ne sont pas renseignees ou autorisees.

Le client cloud.js a ete execute avec un SDK Firebase simule pour les parcours de connexion, file d'attente hors ligne, transactions, erreurs, deux appareils et conflits. Aucun compte Google reel n'a ete utilise.

Ce qui n'a PAS ete certifie ici

La politique du navigateur de test bloque les navigations. Les tests d'interface ont donc simule le stockage local et le transport des fichiers telecharges. Ils ne prouvent pas le fonctionnement du stockage natif de Safari, du reseau Firebase ou de ton installation GitHub Pages.

Non testes en conditions reelles : authentification Google avec un compte, publication Firebase des regles, controle d'acces par l'emulateur officiel, navigateur Safari / iOS, installation sur ecran d'accueil, service worker en HTTPS, autorisations de notification et quotas de ton compte. Les regles de securite sont fournies et doivent etre publiees avant la mise en service. Une verification manuelle sur deux appareils est incluse dans INSTALLATION.html.

Les tests automatises ne constituent ni un audit de securite exhaustif ni une validation medicale du programme ou des associations statistiques.

Reproduire les tests

Le ZIP Sources-et-tests contient les scripts. Node.js execute le moteur et le client cloud simule ; Python, Playwright et Chromium sont necessaires pour les tests d'interface.

node tests/v4-model.test.cjs
node tests/v4-cloud.test.cjs
python tests/v4-browser.py
python tests/v4-setup.py

Les scripts d'interface documentent leurs simulations. Ils ne doivent pas etre presentes comme un essai de connexion Google reel.
