# Knee Quest 4 - Google + GitHub Pages

Application statique, sans etape de compilation. Ouvrir INSTALLATION.html pour le guide et le generateur de firebase-config.js.

1. Exporter le journal de la version precedente.
2. Configurer Firebase Authentication (Google), Firestore Standard (default), publier firestore.rules.
3. Completer firebase-config.js avec la configuration publique Web.
4. Publier tous les fichiers a la racine du depot et activer Pages (main / root).
5. Ajouter le domaine exact nom.github.io dans Firebase Authentication.
6. Importer le JSON dans le site publie, connecter Google et attendre Synchronise. Verifier le second appareil.

Ne pas publier de journal JSON ni de cle privee. Le code public contient les exercices preconfigures, pas votre journal personnel. Aucun projet Firebase ni site GitHub n'a ete deploye automatiquement.

Tests et limites : RAPPORT-TESTS.html. Guide fonctionnel : GUIDE.html.
